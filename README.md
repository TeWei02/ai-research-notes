機器學習與人工智慧研究的個人筆記倉庫，收錄論文摘要、技術筆記與學習資源整理，作為長期累積的知識庫。

## 狀態

> **持續更新中**：以筆記與摘要為主，內容將隨閱讀進度陸續補上。

## 內容規劃

| 類別 | 說明 |
|------|------|
| 論文閱讀摘要 | 重點論文的方法、實驗與結論整理 |
| 機器學習筆記 | 監督式 / 非監督式學習、模型評估等基礎主題 |
| 深度學習筆記 | 神經網路架構、訓練技巧與實務經驗 |
| 學習資源 | 課程、書籍、線上教材與工具連結 |

## 筆記原則

- 摘要以「方法動機 → 核心設計 → 實驗結果」三層結構書寫
- 重要公式與模型以可複現的方式記錄
- 每個主題獨立一篇，方便日後檢索

## 目錄結構

```
ai-research-notes/
├── notes/          # 主題筆記（依主題分類）
├── papers/         # 論文摘要
├── resources/      # 學習資源清單
└── README.md
```
